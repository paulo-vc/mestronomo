                          Configurações

                          O bot está configurado pelo arquivo .env (modo desenvolvimento).

                          1. Crie um bot (2 minutos, uma vez só).
                            Como?

                            New Application → dê um nome → aba Bot → Reset Token → copie o token. Na aba Installation, deixe Install Link em "None" e desmarque Public Bot se quiser que só você o use.

                          2. Cole o token aqui.
                            Fica guardado criptografado neste PC.
                          3. Convide o bot para o servidor da mesa.
